# Cotação USD→BRL diária com AwesomeAPI

> **TLDR**: o plugin `opencode-brl-cost` passa a buscar cotação USD→BRL
> uma vez por dia via AwesomeAPI, exibi-la na barra (`USD: R$ 4,78`), e
> carimbar cada sessão com a taxa do dia para cálculos precisos retroativos.

## Contexto

Hoje o plugin converte USD→BRL com taxa fixa `BRL_PER_USD = 5`. Isso
distorce o valor real dos gastos, especialmente em dias de oscilação forte
do câmbio. O README já elenca _"make exchange rate configurable"_ no roadmap.

A AwesomeAPI (`economia.awesomeapi.com.br`) fornece o par USD-BRL sem
autenticação, com atualização a cada 30s, retornando `bid`/`ask`/`high`/`low`.

## Objetivos

- Buscar cotação USD→BRL uma vez por dia via AwesomeAPI.
- Exibir a cotação vigente na barra do plugin (`app_bottom`), canto direito.
- Carimbar cada sessão com a taxa do dia em que foi criada.
- Calcular totais de dia/semana/mês usando a taxa individual de cada sessão.
- Sobreviver a falhas de rede com cache local e fallback.

## Fora de escopo

- Tracking per-day dentro de uma mesma sessão (tradeoff aceitável: 1 taxa
  por sessão, a do dia de criação).
- Suporte a outros pares de moeda (somente USD→BRL).
- Interface de configuração da taxa (arquivo JSON é editável manualmente).
- Timer de refresh automático (basta reload do plugin ou reinício do OpenCode).

## Decisões de design

### Fonte da cotação

**AwesomeAPI** — endpoint: `GET https://economia.awesomeapi.com.br/json/last/USD-BRL`

Resposta real:
```json
{
  "USDBRL": {
    "bid": "5.1249",
    "ask": "5.1258",
    "high": "5.1366",
    "low": "5.0998",
    "create_date": "2026-09-04 18:29:35"
  }
}
```

Campo usado: **`bid`** (taxa de compra — referência de mercado, igual ao
que Google/Wise exibem como "cotação do dólar").

### Persistência

Arquivo `~/.opencode/brl-cost-rate.json`:
```json
{
  "rate": 5.1249,
  "date": "2026-09-05",
  "timestamp": "2026-09-05T18:29:35.000Z"
}
```
Localizado em `api.state.path.state` (mesmo diretório de `auth.json`).

### Modelo de dados: taxa por sessão

O `Map` de custos ganha um campo `rate`:

```ts
// Antes:
const costs = new Map<string, { cost: number; created: number }>()

// Depois:
const costs = new Map<string, { cost: number; created: number; rate: number }>()
```

Cada entrada carimba a taxa **vigente no momento de `session.created`**.
Se a sessão durar 3 dias, todos os custos dela usam a taxa do dia 1 —
tradeoff aceitável (99% das sessões duram minutos, não dias).

### Estados da cotação e exibição

| Estado | Exibição | Cor (`theme`) |
|--------|----------|---------------|
| Fresca (hoje) | `USD: R$ 4,78` | `textMuted` |
| Cache de ontem (1 dia) | `USD: R$ 4,78` | `warning` |
| Cache stale (2+ dias) | `USD: --` | `warning` |
| Nunca buscou (sem cache) | `USD: --` | `warning` |

Não existe hover em TUI — usamos cor como indicador de frescor.

### Layout da barra

```
┌──────────────────────────────────────────────────────────────────┐
│ dia: R$ 1,50 ◆ semana: R$ 12,30 ◆ mês: R$ 45,67    USD: R$ 4,78 ◆ session: R$ 1,50 ◆ openrouter: R$ 230,40 │
└──────────────────────────────────────────────────────────────────┘
                      esquerda (agregados)                            direita (referência)
```

- `USD` usa `theme.textMuted` (fresco) ou `theme.warning` (stale).
- `session` mantém cor atual (`theme.text`).
- `openrouter` mantém cor atual (`theme.accent`/`theme.success`).
- Quando `USD: --`, o texto é `theme.warning`.

### Ordem de inicialização

1. Dispara `fetchRate()` (AwesomeAPI, 15s timeout) — **não bloqueia**.
2. Dispara `seed()` (lista sessões do SDK) — em paralelo.
3. `seed()` usa cache se disponível, senão fallback `5.0`.
4. Quando `fetchRate()` resolve:
   - Salva `brl-cost-rate.json`.
   - Atualiza o signal `currentRate`.
   - **Sessões já carimbadas mantêm sua taxa original.**
   - Sessões futuras (`session.created`) usarão a nova taxa.
   - Dispara `refresh()` para atualizar a barra (a cotação exibida muda).

### Cálculo dos totais

```ts
// Antes — taxa global:
const total = sum(entry.cost) * BRL_PER_USD

// Depois — taxa individual por sessão:
const total = sum(entry.cost * entry.rate)
```

A função `formatBRL` passa a receber BRL diretamente (não multiplica mais
por uma constante global). Renomeada para `formatBRLValue(brl: number)`.

### Fallback

- Cache existe e é de hoje → usa cache.
- Cache existe e é de ontem → usa cache (cor `warning`).
- Cache é de 2+ dias atrás → `null` (exibe `--` em `warning`).
- Sem cache → `null` + fallback `5.0` para carimbar sessões (mas exibe `--`
  até a API responder).

## Mudanças

### `src/index.tsx`

**Removido:**
- `const BRL_PER_USD = 5`

**Adicionado:**
- `import { writeFileSync } from "node:fs"` (já importa `readFileSync`).
- Tipo `RateCache = { rate: number; date: string; timestamp: string }`.
- Função `loadCachedRate()`: lê `brl-cost-rate.json`, retorna `RateCache | null`.
- Função `saveCachedRate(rate: number)`: escreve `brl-cost-rate.json`.
- Função `rateState(cache: RateCache | null)`: determina estado
  (`"fresh" | "stale_one_day" | "stale" | "unavailable"`).
- Função `fetchRate()`: chama AwesomeAPI, retorna `number` (bid).
- Signal `currentRate: () => number | null` (taxa vigente, null se
  `--`).
- Signal `rateStatus: () => "fresh" | "stale_one_day" | "stale" | "unavailable"`.

**Modificado:**
- `costs` Map: adicionar campo `rate: number`.
- `seed()`: ao criar entrada, usar `currentRate ?? 5.0` como `rate`.
- `refresh()`: cada entrada calcula `entry.cost * entry.rate`; soma em BRL;
  usa `formatBRLValue(brl)`.
- `formatBRL(usd)` → `formatBRLValue(brl: number)`: recebe BRL, só formata.
- Handler `session.created`: carimba `rate: currentRate ?? 5.0`.
- Slot `app_bottom` (direita): adicionar `<text>` com `USD: R$ X,XX` ou
  `USD: --`, cor condicional baseada em `rateStatus`.
- `tui()`: adicionar `fetchRate()` paralelo ao `seed()`, com `.then()`
  que salva cache e atualiza signals.

### Arquivo novo

`~/.opencode/brl-cost-rate.json` — criado automaticamente na primeira
busca bem-sucedida. Não versionado.

## Como verificar

- `npm run build && npm run typecheck` — zero erros.
- **Manual**: abrir OpenCode, ver `USD: R$ X,XX` na barra da sessão.
- **Cache**: fechar, reabrir — mesma cotação (sem nova chamada à API).
- **Stale**: editar `brl-cost-rate.json` com data de ontem — barra mostra
  `USD: R$ X,XX` em amarelo (`warning`).
- **Offline**: desconectar rede, deletar cache, abrir OpenCode — `USD: --`
  em warning, mas custos calculados com fallback `5.0`.
- **Sessão antiga**: criar sessão, depois editar `brl-cost-rate.json` com
  taxa diferente, criar nova sessão — cada sessão usa sua própria taxa
  nos totais de dia/semana/mês.
